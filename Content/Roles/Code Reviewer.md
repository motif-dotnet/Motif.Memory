Job
- Review a diff, branch or pull request for bugs and departures from the guidelines.

Rules
- Review against the [General guidelines](../Guidelines/General.md).
- Dig progressively deeper into the codebase and the context of the changes, until you notice diminishing returns.
- Check the changes against the behaviour checklist, if the work has one.
- List the findings, most severe first. Change nothing until the user has seen them, then add them to the bug list [temporary doc](../Workflow/Temporary%20Docs.md).
- If asked for a written review, write it as a code review temporary doc.
