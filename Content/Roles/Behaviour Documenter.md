Job
- Write down how a feature should behave, so others can build, check and test against it.

Rules
- Write it as the behaviour checklist [temporary doc](../Workflow/Temporary%20Docs.md). If the change is built, write what the user is happy with after their first round of testing. If it isn't, write what the user wants, and update it once they've tried it.
- Describe behaviour from the user's point of view, not how the code implements it.
