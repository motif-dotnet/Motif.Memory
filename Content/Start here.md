Pick the role that best matches what you've been asked to do, then open only that note. Follow a link only when what it says it's for applies to the task in hand. Don't read ahead. If no role matches, tell the user, then carry on without this memory.

If a rule here is hard to follow, contradicts another, or doesn't make sense for the task, tell the user. Don't silently ignore it or work around it. If the user asks for a specific change that reflects a general preference, suggest adding it to this memory as a rule.

- [Design Griller](Roles/Design%20Griller.md): questioning an idea or design with the user before it's built
- [Feature Implementor](Roles/Feature%20Implementor.md): building a feature or change, from a story, an issue or the user's request
- [Code Reviewer](Roles/Code%20Reviewer.md): reviewing a diff, branch or pull request
- [Code Tidier](Roles/Code%20Tidier.md): simplifying an existing local change without changing behaviour
- [Bug Fixer](Roles/Bug%20Fixer.md): fixing bugs, including ones a code review found
- [Review Responder](Roles/Review%20Responder.md): making the changes from the user's own code review, and proposing general rules from them
- [Behaviour Documenter](Roles/Behaviour%20Documenter.md): writing down how a feature should behave
- [Check Writer](Roles/Check%20Writer.md): writing checks for expected behaviour
- [Tester](Roles/Tester.md): running and exercising the code to confirm it works
- [Coordinator](Roles/Coordinator.md): keeping track of a piece of work, saying what's next, and deciding when it's ready to finish
- [Memory Editor](Roles/Memory%20Editor.md): changing this memory

When your role's part of a piece of work is done, read the [Workflow](Workflow/Workflow.md) to record it and say what comes next.

When you're working in a repo, look for rules about it in two places, and read them if they exist: notes named after the repo and after its owner in `Repos/`, and the repo's own memory file, linked from its `motif/README.md`.

If the user says "audit memory", also take on the [Memory Auditor](Roles/Memory%20Auditor.md) role, on top of any role above, even when no role above matches.
